# FirstJoinClass

Paper-плагин: при первом входе игрока автоматически выполняет `/class` от его имени.

## Сборка

```bash
mvn package
```

Готовый файл: `target/FirstJoinClass.jar` — положить в папку `plugins` сервера.

## Настройка

`plugins/FirstJoinClass/config.yml`:

```yaml
enabled: true
command: "class"          # что выполнить (без слэша)
delay-ticks: 20           # задержка перед выполнением (20 тиков = 1 сек)
only-new-players: true    # только те, кто ещё ни разу не заходил
warn-on-failure: true     # писать в консоль, если команда не выполнилась
```

После изменения конфига: `/fjc reload`.

## Команды

- `/fjc reload` — перечитать конфиг
- `/fjc reset <игрок>` — сбросить отметку (игрок должен быть онлайн), чтобы команда сработала при следующем входе
- `/fjc run [игрок]` — выполнить команду прямо сейчас

Право: `firstjoinclass.admin` (по умолчанию только у операторов).

## Как это работает

Отметка о показе хранится в PersistentDataContainer игрока, поэтому команда
не повторяется при последующих входах. Если `/class` не существует или у игрока
нет прав, отметка не ставится — попытка повторится при следующем входе.
